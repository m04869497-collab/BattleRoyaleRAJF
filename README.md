# BattleRoyaleRAJF

نموذج أولي محلي ثلاثي الأبعاد لـ Unity 6، قابل للتجربة على الكمبيوتر والهاتف. يتضمن مباراة تدريبية ضد bots محليين فقط؛ لا يوجد خادم أو multiplayer، وليس لعبة تجارية مكتملة.

## حالة المشروع

هذا المستودع يحتوي مصدر النموذج وأداة إنشاء المشهد، لكنه لا يتضمن `ProjectSettings/ProjectVersion.txt` أو مشهدًا محفوظًا بعد. لذلك لا تفتحه كمشروع Unity مكتمل مباشرة:

1. أنشئ مشروعًا جديدًا باسم `BattleRoyaleRAJF` من Unity Hub باستخدام إصدار Unity 6 الذي تختاره.
2. انسخ مجلد `Assets/` وملف `Packages/manifest.json` من هذا المستودع إلى مجلد المشروع الجديد. احتفظ بملفات `ProjectSettings/` التي أنشأها Unity، ولا تغيّر إصدار المحرر فيها يدويًا.
3. افتح المشروع وانتظر انتهاء استيراد الحزم وتجميع السكربتات.
4. من القائمة اختر **Tools → RAJF → Create Prototype Scene**. تحفظ الأداة المشهد في `Assets/Scenes/RAJFPrototype.unity` وتضيفه إلى قائمة مشاهد البناء.
5. افتح المشهد واضغط Play.

تُنشأ أرضية وعوائق وشخصية اللاعب والخصوم والكاميرا والإضاءة والـ Canvas من أشكال Unity البدائية، من دون تنزيل أصول رسومية خارجية. أداة المحرر تنشئ أيضًا مواد ألوان بسيطة محليًا.

## التحكم

- الكمبيوتر: `WASD` أو الأسهم للحركة، `Mouse 0` أو `Space` لإطلاق النار، و`E` لاستخدام القدرة.
- الهاتف: أزرار الاتجاهات وإطلاق النار والقدرة التي تظهر على الشاشة.
- التصويب من منتصف الكاميرا، والمدى محدود. الخصوم bots تدريبية محلية وليست لاعبين حقيقيين.

يدعم كود الحركة وإطلاق النار والقدرة حزمة Input System الجديدة عند تفعيلها، كما يدعم Input Manager القديم من دون استخدام `Input.GetAxis`. في **Edit → Project Settings → Player → Active Input Handling** اختر **Input System Package (New)** أو **Both** إذا أردت النظام الجديد؛ تأكد من تثبيت حزمة Input System من Package Manager. يمكن استخدام **Input Manager (Old)** للاختبار أيضًا.

## الشخصيات والقدرات

- **Scavenger:** زيادة سرعة الحركة 50% لمدة 3 ثوانٍ؛ انتظار 12 ثانية.
- **Phantom:** إخفاء النموذج بصريًا لمدة 4 ثوانٍ؛ انتظار 16 ثانية.
- **Mystic Medic:** استعادة 35 نقطة صحة فورًا؛ انتظار 18 ثانية.
- **Heavy Defender:** إضافة 35 نقطة درع مؤقت لمدة 6 ثوانٍ؛ انتظار 20 ثانية.

يعرض HUD مدة التأثير النشط ووقت الانتظار. القيم مخصصة للتجربة ويمكن تعديلها في `GameSession`.

## Android وGitHub Actions

1. ثبّت Unity 6 مع **Android Build Support** وAndroid SDK/NDK وOpenJDK من Unity Hub.
2. أنشئ المشروع وافتحه مرة واحدة، ثم أضف ملفات `ProjectSettings/` التي أنشأها Unity إلى المستودع. ملف `ProjectSettings/ProjectVersion.txt` هو المرجع لإصدار المحرر.
3. أضف Secret باسم `UNITY_LICENSE` من إعدادات المستودع في GitHub. خزّن بيانات الترخيص هناك فقط؛ لا تضعها في هذا المستودع أو في المحادثة.
4. شغّل **RAJF Android Build** يدويًا من تبويب Actions، أو ادفع تغييرات إلى `main` أو `master`.

يقرأ workflow قيمة `m_EditorVersion` مباشرة من `ProjectSettings/ProjectVersion.txt` ويمررها إلى GameCI، ويتحقق أن الإصدار من Unity 6 (`6000.x`). إذا لم يكن ملف الإصدار موجودًا بعد، يتخطى Job البناء مع تحذير بدل استخدام إصدار مخمّن. عند تشغيل البناء يرفع APK كـ artifact، ويُظهر فشلًا إذا لم يُنتج الملف. لم يُفترض نجاح أي بناء قبل تشغيله فعليًا.

## ملاحظات

- العاصفة والخصوم والقدرات تعمل محليًا داخل الجهاز.
- المشهد يُنشأ من قائمة Unity؛ لا يوجد ملف Scene محفوظ في المستودع قبل تشغيل الأداة.
- النموذج مخصص للتجربة والتطوير، وليس لعبة أونلاين أو إصدارًا تجاريًا مكتملًا.
